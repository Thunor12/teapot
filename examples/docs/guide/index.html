Guide

Get a working teapot_listen server in a few minutes. API and Wait cover the rest.

1. Get the header

Use amalgamated stb_teapot.h from this repo. From the repo root:

./nob

That regenerates stb_teapot.h and runs tests. For these interactive docs only: ./nob doc.

2. Minimal listen server

One GET /ping handler on loopback. Bind host is dotted IPv4 — use "127.0.0.1", not "localhost".

#define STB_TEAPOT_IMPLEMENTATION
#include "stb_teapot.h"

static teapot_response ping(const teapot_request *req)
{
    (void)req;
    return teapot_json(TEAPOT_HTTP_OK, "{\"ok\":true}");
}

int main(void)
{
    teapot_route routes[] = {
        {TEAPOT_GET, "/ping", ping},
    };
    teapot_server server = {
        .port = 8080,
        .routes = routes,
        .route_count = 1,
        .bind_host = "127.0.0.1",
    };
    return teapot_listen(&server);
}

curl http://127.0.0.1:8080/ping → {"ok":true}.
