Routes

Exact path match against a static teapot_route table. Method + path + handler.

Overview Routes Responses Limits

Table shape

Each route is method, path string, and handler returning teapot_response by value.

teapot_route routes[] = {
    {TEAPOT_GET,  "/ping",  ping},
    {TEAPOT_GET,  "/hello", hello},
    {TEAPOT_POST, "/echo",  echo},
};

Matching

  • Exact path after stripping the query string (? and beyond).
  • No path parameters and no globbing in this release.
  • Unknown route → 404.
  • Handler is teapot_response (*)(const teapot_request *).

Request view

Handlers read method, path, headers, and optional body via teapot_request. Do not free the request; the library owns connection lifetime.
