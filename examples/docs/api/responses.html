Helpers

  • teapot_json / teapot_text / teapot_bytes / teapot_html
  • teapot_response_header / teapot_response_headerf — copy name/value; reject CR/LF and reserved names
  • Wire order: status → Content-Type → Content-Length → Connection: close → extras → body
teapot_response r = teapot_html(TEAPOT_HTTP_OK, "<p>hi</p>");
teapot_response_header(&r, "HX-Trigger",
    "{\"teapot:flash\":{\"target\":\"#status-line\"}}");
return r;
