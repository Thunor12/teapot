Limits

Honest edges: timeouts, HTTP subset, Connection: close, and who owns the socket.

Overview Routes Responses Limits

HTTP subset

Request line + headers + Content-Length body. No header folding, no chunked encoding, no pipelining. Transfer-Encoding is 400. Duplicate Content-Length is 400 unless values parse equal. Extra bytes after the body in the first read are 400. Oversize headers and bodies are 400.

Timeouts and close

  • Recv timeout: TEAPOT_RECV_TIMEOUT_MS (default 5000)
  • Send timeout: TEAPOT_SEND_TIMEOUT_MS (default 5000)
  • Responses include Connection: close

Socket ownership

  • teapot_serve_client does not close the client socket.
  • teapot_handle_client_connection takes ownership and closes it.
  • Do not close the same fd again.

Bind address

Set bind_host to "127.0.0.1" for loopback. NULL binds 0.0.0.0. Value is a dotted IPv4 address, not a hostname: "localhost" fails.

Out of scope here

TLS and HTTP/2 belong in a reverse proxy. HTML templates are optional and not this release. Keep-alive is not offered.
